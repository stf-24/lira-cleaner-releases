# Lira Launcher

Запуск ЛИРА-САПР и очистка результатов расчёта.

<br clear="left">

## Скачать

**[⬇ Скачать Lira Launcher 1.0.0 (установщик .exe)](https://github.com/stf-24/lira-cleaner-releases/releases/download/v1.0.0/LiraLauncher-Setup-1.0.0.exe)**

Все версии — на странице [Releases](https://github.com/stf-24/lira-cleaner-releases/releases).

Установка не требует прав администратора. Установленная программа сама проверяет
обновления при запуске и предлагает установить новую версию.

## Что умеет

- Показывает, какие расчётные схемы занимают место в папке рабочих файлов ЛИРА-САПР (Work).
- Удаляет результаты выбранных схем.
- Находит и удаляет бэкапы моделей (`.~lir`, `.~~lir`).
- Отмечает результаты, для которых не найдена модель `.lir`.

Файлы моделей `.lir` программа не удаляет никогда. Удаление — только по команде
пользователя, с подтверждением, по умолчанию в корзину Windows.

## Условия

Автор: Stf. Программа распространяется бесплатно и безвозмездно и предоставляется
«как есть», без каких-либо гарантий. Lira Launcher — независимая программа и не связана
с правообладателем ЛИРА-САПР.

## История изменений

### [1.0.0](https://github.com/stf-24/lira-cleaner-releases/releases/tag/v1.0.0)

Дата выпуска: 27.10.2026

Номер версии утвердил: Stf

#### Новое
- Программа теперь называется Lira Launcher (раньше — LiraCleaner) и умеет запускать ЛИРА-САПР.
- Раздел «Запуск»: установленные версии ЛИРА-САПР находятся автоматически, каждую можно запустить одной кнопкой и отметить основной.
- Модели .lir из рабочих папок со списком последних, поиском и кнопками «Открыть в 2024 / 2022»; двойной щелчок открывает модель в подходящей версии.
- Предупреждение, если модель из папки данных одной версии ЛИРЫ открывается в другой.
- Рабочие папки: программа работает с файлами только внутри выбранных вами папок.
- Если к рабочей папке пропал доступ, она убирается из списка, а программа предупреждает об этом и предлагает вернуть её позже.
- «Показать в папке» по правой кнопке мыши: Проводник открывается с уже выделенными файлами схемы или бэкапами модели.
- Новый вид в стиле Windows 11: навигация слева, страница «Настройки», выбор темы — как в системе, светлая или тёмная.
- Логотип программы в панели задач и на ярлыках.

#### Исправлено
- После автоматического обновления программа больше не показывает ошибку «Failed to load Python DLL».
- Заголовки и колонки таблиц не съезжают и не обрезаются, в том числе в узком окне.

#### Важно для пользователей
- Обновление ставится поверх LiraCleaner: старые ярлыки заменяются на «Lira Launcher», настройки и рабочие папки сохраняются.
- Файлы моделей .lir программа по-прежнему не удаляет никогда.

### [0.1.0](https://github.com/stf-24/lira-cleaner-releases/releases/tag/v0.1.0)

Дата выпуска: 26.10.2026

Номер версии утвердил: Stf

#### Новое
- Первая версия программы.
- Анализ папки рабочих файлов ЛИРА-САПР (Work): какие расчётные схемы занимают место, сколько файлов, объём, дата изменения, есть ли результаты расчёта.
- Удаление результатов выбранных расчётных схем — только их файлов, без затрагивания других схем.
- Поиск и удаление бэкапов моделей (.~lir, .~~lir) с группировкой по моделям.
- Настраиваемые папки моделей: поиск .lir и бэкапов, в том числе во вложенных и сетевых папках.
- Отметка результатов, для которых не найдена модель .lir.
- Установщик и автоматическая проверка обновлений при запуске.

#### Важно для пользователей
- Файлы моделей .lir программа не удаляет никогда.
- Удаление выполняется только после подтверждения, по умолчанию — в корзину Windows.
- Если рядом с бэкапами нет файла .lir, программа предупреждает: бэкап может быть единственной копией модели.
- Перед удалением результатов закройте схему в ЛИРА-САПР.
